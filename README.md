# 礼物统计插件 (astrbot_plugin_gift_stats)

> 基于 AstrBot 框架的 B 站直播间礼物数据统计插件，支持多群直播间绑定、日期范围查询、个人礼物贡献查询

---

## 功能特性

- **礼物查询**：
  - 当天统计（默认）
  - 最近 N 天（1～30 天）
  - 指定日期范围（YYYY-MM-DD）

---

## 安装与配置
### ！！重要！！
<a href="https://bot.star-yu.cn" target="_blank" style="font-size: 1.4em; font-weight: bold;">星予</a> 需前往注册账号，并且添加直播间

### 1. 安装插件
- 通过从 AstrBot 插件市场安装
- 或手动将 `astrbot_plugin_gift_stats` 文件夹放入 AstrBot 的 `plugins/` 目录


### 2. 配置参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `username` | string | 空 | **必填**：登录用户名 |
| `password` | string | 空 | **必填**：登录密码 |
| `merge_forward` | bool | true | 是否尝试合并转发多页图片 |
| `send_separately` | bool | true | 当合并转发关闭时，是否逐张发送所有图片 |
| `single_image_output` | bool | false | 开启后生成一张完整长图，不分页 |
| `single_image_max_users` | int | 15 | 每页显示用户数，范围 1～20 |

---

### 指令

| 指令 | 说明 |
|------|------|
| `/礼物统计` | 获取**当天**的礼物统计 |
| `/礼物统计 [天数]` | 获取**最近 N 天**的礼物统计（N=1~30） |
| `/礼物统计 YYYY-MM-DD YYYY-MM-DD` | 获取**指定日期范围**的礼物统计 |
| `/礼物页 [页码]` | 跳转到指定页码 |
|------|------|
| `/礼物统计房间` | 列出所有可用直播间及其序号 |
| `/礼物房间 绑定 [序号]` | 将当前群绑定到指定房间，序号从列表中获取 |
|------|------|
| `/礼物统计 绑定 [UID]` | 绑定您的 B 站 UID |
| `/礼物统计 解绑` | 解除已绑定的 UID |
| `/礼物统计 贡献` | 查询已绑定 UID 的礼物贡献，生成专属图片 |
|------|------|
| `/礼物统计帮助` | 显示本帮助信息 |
